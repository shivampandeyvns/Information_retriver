# Information Retrieval System

## Overview

This project implements a complete Information Retrieval (IR) System using Python and Streamlit. The application demonstrates various indexing and retrieval techniques including:

- Text Preprocessing
- Stemming and Lemmatization
- Inverted Index Construction
- Phrase Query Processing (Biword Index and Positional Index)
- BST vs B-Tree Performance Comparison
- Tolerant Retrieval using K-Gram Index
- Edit Distance Based Spell Correction
- Wildcard Query Processing

---

## Running the Application

Navigate to the project directory and run:

bash streamlit run app.py 

After execution, Streamlit will automatically launch the application in your default web browser.

Default URL:

text http://localhost:8501

## How to Use the Application

### Step 1: Upload Documents

- Open the application.
- Upload one or more .txt files using the file uploader.
- The uploaded documents will be processed automatically.

### Step 2: Preprocessing

- Navigate to the Preprocessing tab.
- View the tokenized and cleaned text after preprocessing.

### Step 3: Stemming vs Lemmatization

- Open the Stem vs Lemma tab.
- Compare the outputs generated by stemming and lemmatization.

### Step 4: Phrase Query Processing

- Open the Phrase Query tab.
- Enter phrase queries such as:

text machine learning artificial intelligence 

- Compare the results returned by:
  - Biword Index
  - Positional Index

### Step 5: BST vs B-Tree Comparison

- Open the BST vs B-Tree tab.
- Review document retrieval results and execution times for both indexing structures.

### Step 6: Tolerant Retrieval

- Open the Tolerant Retrieval tab.

Example misspelled query:

text machian 

Example wildcard query:

text mach* 

- View spelling corrections, edit distances, and wildcard matches.

### Step 7: Experimental Analysis

- Review the observations and conclusions generated from:
  - Stemming vs Lemmatization
  - Phrase Query Processing
  - BST vs B-Tree Comparison
  - Tolerant Retrieval
